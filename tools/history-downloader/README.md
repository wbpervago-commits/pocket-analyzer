# Отдельный загрузчик истории Pocket Option

Этот тест не меняет рабочее расширение Pocket Analyzer Quote Bridge 1.0.0 и не открывает сделки.

## Запуск

1. Убедитесь, что Python 3 установлен на компьютере.
2. Откройте Pocket Option и войдите в аккаунт.
3. Откройте DevTools клавишей F12, вкладку Network, фильтр WS (или Socket).
4. Выберите соединение `wss://...po.market/socket.io/`.
5. Откройте Messages / Frames и найдите исходящее сообщение, начинающееся с `42["auth",`.
6. Скопируйте сообщение целиком. Не публикуйте его в чатах и не отправляйте кому-либо.
7. Запустите `run_history.bat`. В появившееся скрытое поле вставьте сообщение и нажмите Enter.

Загрузчик подключается к WebSocket Pocket Option через библиотеку PocketOptionApi и запрашивает 1440 минутных свечей EURUSD_otc. Он сохраняет только свечи за последние 24 часа в `EURUSD_otc_M1_history.json`.

Если сервер не вернёт историю, программа покажет текст ошибки. В этом тесте нет операций открытия или закрытия сделок.

Источник клиента: https://github.com/chema-creator/PocketOptionApi
